# Aplikasi Cipher Klasik

Project tugas mata kuliah Kriptografi menggunakan Python.

## Aplikasi

### 1. Caesar Cipher
Metode substitusi dengan menggeser huruf berdasarkan kunci.

Fitur:
- Enkripsi
- Dekripsi
- Kunci 0–25

Jalankan:
```bash
python caesar_cipher.py
```

### 2. Vigenere Cipher

Metode substitusi polialfabetik yang menggunakan huruf atau kata sebagai kunci.

Fitur:

Enkripsi
Dekripsi
Kunci berupa huruf

Jalankan:
```bash
python vigenere_cipher.py
```

### 3. Columnar Transposition Cipher

Metode transposisi yang mengubah posisi karakter berdasarkan susunan kolom.

Fitur:

Enkripsi
Dekripsi
Kunci berupa kata

Jalankan:
```bash
python columnar_transposition.py
```
